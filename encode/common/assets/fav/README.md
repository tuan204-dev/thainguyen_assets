# Favicon set - Bao Thai Nguyen

Generated from the current CMS favicon at
`https://cdn.baothainguyen.vn/original/assets/favicon_2.ico`. The rectangular
logo is centered on a square canvas without distortion.

| File | Platform |
|---|---|
| `favicon.ico` (16/32/48) | Legacy browsers and address bars |
| `favicon.svg` | Modern browsers |
| `favicon-16x16 / 32x32 / 48x48 / 96x96.png` | Browser tabs |
| `apple-touch-icon.png` (180, white background) | iOS/iPadOS home screen |
| `android-chrome-192x192 / 512x512.png` | Android and PWA |
| `android-chrome-maskable-*.png` (70% safe zone) | Android adaptive icon |
| `safari-pinned-tab.svg` | Safari pinned tab |
| `mstile-70/150/310.png` + `browserconfig.xml` | Windows tiles |
| `site.webmanifest` | PWA manifest (VI - baothainguyen.vn) |
| `site-en / site-cn / site-kr.webmanifest` | PWA manifest for the en/cn/kr subdomains |

The deployed base URL is
`https://r2-thainguyen.media-soft.cloud/encode/common/assets/fav/`.
Use a version query when the files change because R2 assets are cached for 30
days.
